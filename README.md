# 🎯 Overview

The **Stats O'Locked (SOL)** website is a modern, visually immersive static website designed to:

- Represent a technical club identity
- Showcase multiple domains
- Display leadership structure
- Promote recruitment
- Present events and achievements
- Provide strong visual branding

The design philosophy combines:

- Cyberpunk aesthetics
- Data visualization styling
- Neon glow UI elements
- Glassmorphism
- Smooth transitions & animations
- Clean typography hierarchy

- Digital lock tumbler animation

- Animated gradient brand typography

- Particle canvas animation
- Smooth fade-out transition into main content
